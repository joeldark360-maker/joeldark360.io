# Cifrador César

**Autor: Joel**

## Descripción
Este proyecto consiste en una página web para cifrar texto usando el método del cifrado César. El usuario escribe un texto y puede ajustar el desplazamiento con un control deslizante para ver el resultado cifrado.

## Objetivo
Crear una herramienta sencilla e interactiva para practicar conceptos de HTML, CSS y JavaScript mediante un ejemplo de cifrado clásico.

## Archivos del proyecto
- `index.html`: contiene la estructura de la página, el campo de texto y el control deslizante.
- `index.css`: contiene los estilos visuales de la página.
- `index.js`: contiene la lógica de interacción y el cifrado.

## Tecnologías utilizadas
- **HTML:** estructura el contenido de la página.
- **CSS:** define el diseño y la apariencia.
- **JavaScript:** procesa el texto y actualiza el resultado según el desplazamiento seleccionado.

## ¿Cómo utilizarlo?
1. Abre `index.html` en tu navegador.
2. Escribe el texto que deseas cifrar.
3. Mueve el control deslizante para elegir el desplazamiento.
4. Observa el texto cifrado que aparece en pantalla.

## ¿Qué es el cifrado César?
Es un método de sustitución en el que cada letra se desplaza un número determinado de posiciones en el alfabeto. Por ejemplo, con un desplazamiento de 3, la letra `A` se transforma en `D`.

## Cómo ejecutar el proyecto
1. Coloca `index.html`, `index.css` e `index.js` en la misma carpeta, junto con cualquier otro recurso que el proyecto necesite.
2. Comprueba que los nombres de los archivos enlazados en el HTML coincidan con los archivos que tienes.
3. Abre `index.html` en un navegador web.

## Nota
El cifrado César es útil para aprender conceptos básicos de criptografía, pero no debe utilizarse para proteger información confidencial porque es fácil de descifrar.
